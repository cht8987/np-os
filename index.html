Why It Matters

AI 时代，记忆就是主权。

🏛️ 数据自有产权

你的日记、决策、账单、教训，全部是你硬盘上的纯 Markdown 文件。不锁在任何平台里，不依赖任何订阅，二十年后依然打得开。平台会倒闭，纯文本不会。

📈 经验复利

大多数人的人生经验在三个月后蒸发。LotusOS 把每一次决策、每一个教训沉淀为可检索的资产 —— 让你不再重复踩同一个坑，让 AI 越来越懂你。

🧘 认知减负

「先想清楚放哪」是传统笔记最大的暴政。LotusOS 把分类的认知负担全部转移给机器，你的大脑只负责一件事：产生想法。做减法是美德。

🤝 真正的 AI 协作

通用 AI 不认识你。LotusOS 给 AI 一份关于你的完整上下文 —— 你的目标、原则、历史、反目标 —— 让每一次对话都站在你 14 年经验之上，而不是从零开始。

Personal Growth

Under The Hood

克制的技术，为了二十年后还能跑。

没有花哨框架，没有供应商锁定。每个技术选型都回答同一个问题：十年后它还在吗？

📦 存储层

纯 Markdown + YAML

人类可读、Git 友好、永不过时的开放格式

⚙️ 引擎层

Python 标准库（零依赖）

macOS 自带环境直接跑，无需 pip install 任何东西

🖥️ 显示层

Obsidian + 自带插件

可替换的显示层，个人使用免费

📱 移动端

Expo 54 · React Native · PWA

OSMIND App：iOS / Android / 浏览器全覆盖

🤖 智能层

可插拔 LLM

默认 DeepSeek 高性价比，一行配置切换任意 OpenAI 兼容 API

🧠 记忆层

Hindsight 语义引擎

本地 Docker 容器，向量检索，数据不出家门

⏰ 调度层

macOS launchd

系统级定时，睡眠错过自动补跑，无守护进程

🌐 网关层

本地 HTTP Gateway

手机唯一写入口，配对 Token 鉴权，局域网即用
